# TutorTrack

[![CI Status](https://github.com/AY2627S1-CS2103T-F14a-3/tp/actions/workflows/gradle.yml/badge.svg)](https://github.com/AY2627S1-CS2103T-F14a-3/tp/actions/workflows/gradle.yml)

![TutorTrack interface](images/Ui.png)

**TutorTrack is a desktop application for private tutors who manage multiple students.** It keeps student contact details, academic information, notes, and lessons together in one place. TutorTrack is optimised for tutors who prefer fast keyboard-driven commands while retaining the benefits of a graphical interface.

## Features

* **Student records**: store contact details, school level, subject, tags, and free-form notes.
* **Quick search**: find students by name, or filter by school level, subject, and tags.
* **Lesson scheduling**: set one-off and weekly recurring lessons, with automatic detection of timetable clashes.
* **Lesson overview**: see your earliest upcoming lesson and sort students by lesson time.
* **Local storage**: your data is saved automatically to a file on your computer.

## Get started

1. Install Java 25.
1. Download `TutorTrack.jar` from the [latest release](https://github.com/AY2627S1-CS2103T-F14a-3/tp/releases).
1. Follow the [Quick Start in the **User Guide**](UserGuide.html#quick-start).

For how TutorTrack is built, see the [**Developer Guide**](DeveloperGuide.html).
