# TutorTrack

![Ui](docs/images/Ui.png)

**TutorTrack is a desktop contact-management application for private tutors who manage multiple students.**

TutorTrack aims to help tutors store student contact details, identify students quickly, and record each student's next lesson. It is optimised for tutors who prefer fast keyboard-driven commands while retaining the benefits of a graphical interface.

* To start using TutorTrack, see the [User Guide](docs/UserGuide.md).
* For information about the design and implementation, see the [Developer Guide](docs/DeveloperGuide.md).
